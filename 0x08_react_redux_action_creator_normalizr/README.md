# 0x08. React Redux action creator+normalizr

This project focuses on the core concepts of Redux, particularly action creators, actions, async actions, Normalizr, and normalizing state shapes.

## Tasks
- **0. Read data from a JSON**: Create schema/notifications.js and test it.
- **1. Normalize a nested JSON**: Set up Normalizr schemas.
- **2. Filter a normalized Schema**: Use the normalized dataset.
- **3. Create actions for the course list**: Implement action types and creators for courses.
- **4. Create actions for the UI**: Implement action types and creators for UI events.
- **5. Create actions for the notification list**: Implement action types and creators for notifications.
- **6. Bound the actions**: Bind action creators using dispatch.
- **7. Async Action Creators**: Implement async redux actions with Redux Thunk.
