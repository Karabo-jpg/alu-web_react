# React Redux reducer+selector

This project focuses on the core concepts of Redux reducers and selectors.

## Tasks
- **0. Write a basic reducer**: Create `uiReducer.js` and tests.
- **1. Use Immutable for the UI Reducer**: Update `uiReducer.js` to use `Immutable.js`.
- **2. Create a reducer for Courses**: Create `courseReducer.js` and tests.
- **3. Create the reducer for notifications**: Create `notificationReducer.js` and tests.
- **4. Normalizr & Immutable**: Update reducers to use `normalizr` and `Immutable.js`.
- **5. Selectors**: Create `notificationSelector.js` and tests.
